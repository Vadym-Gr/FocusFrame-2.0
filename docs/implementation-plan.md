# План реалізації FocusFrame

## Правила роботи

1. Реалізуємо один етап, перевіряємо результат і зупиняємося.
2. Власник самостійно виконує commit і push на GitHub.
3. Наступний етап починається лише після окремого запиту продовжити.
4. Вимоги користувача мають пріоритет; у розбіжностях між макетом і ТЗ
   орієнтуємося на Figma.
5. Питання, що впливають на вигляд чи поведінку, узгоджуємо перед відповідним
   етапом. Не додаємо непогоджений бекенд.

- [x] 1. Основа: очищення шаблону, modern-normalize, Prettier, PostCSS,
      локальний DM Sans, палітра, контейнери, favicon і семантичний каркас.

- [x] 4. Our Courses та спільний механізм перегляду карток.
- [x] 5. Our Mentors із механізмом перегляду карток.

- [x] 7. Reviews із механізмом перегляду карток.

      production-збірки й опублікованого сайту.

## Поведінка карток

- Курси, ментори та відгуки доступні незалежно від кількості.
- Шеврони розміщені обабіч області карток по центру її висоти.
- Якщо видно всі картки, обидві кнопки неактивні.
- На межах відповідна кнопка неактивна; без нескінченного чи автоматичного
  перемикання за замовчуванням.
- На планшеті й мобільному підтримуються свайпи без блокування вертикального
  прокручування; також доступне клавіатурне керування.
- Кількість видимих карток і компонування узгоджуються з макетом.

## Перевірки кожного етапу

Форматування, production-збірка, поведінка змінених елементів, відсутність
горизонтального прокручування від 320 px. Перевіряємо ширини 320, 375, 768, 1280
і 1440 px та проміжні розміри. Після додавання перекладу перевіряємо
компонування з довшими текстами.
