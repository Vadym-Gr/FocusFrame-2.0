# FocusFrame 2.0

Адаптивний сайт школи фотографії за макетом Figma. Стек: семантичний HTML, CSS і
JavaScript, збірка Vite. Початкова версія працює без бекенду.

[Макет Figma](https://www.figma.com/design/RXTP1SehqgqMzpvxD82chE/FocusFrame-2.0--Copy-?node-id=0-1)

## Локальний запуск

Потрібні Node.js 24 та npm. Версію Node.js також зазначено в `.nvmrc`.

```sh
npm ci
npm run dev
```

Адреса сервера з'явиться в терміналі; зазвичай це http://localhost:5173/. У
Windows PowerShell, якщо запуск `npm.ps1` заборонено, використовуй `npm.cmd`
замість `npm`.

## Команди

| Команда                | Призначення                                 |
| ---------------------- | ------------------------------------------- |
| `npm run dev`          | Сервер розробки з автоматичним оновленням   |
| `npm run build`        | Production-збірка в `dist/`                 |
| `npm run preview`      | Локальний перегляд production-збірки        |
| `npm run format`       | Форматування вихідного коду та документації |
| `npm run format:check` | Перевірка форматування без змін файлів      |

Після `npm run build` та `npm run preview` відкрий адресу з термінала зі шляхом
`/FocusFrame-2.0/` (зазвичай http://localhost:4173/FocusFrame-2.0/).

## Структура

- `src/index.html` — метадані та підключення секцій.
- `src/partials/` — семантична розмітка окремих блоків.
- `src/css/styles.css` — точка підключення нормалізатора, шрифтів і стилів.
- `src/css/tokens.css` — спільні кольори, шрифти та інші базові значення.
- `src/css/container.css` — адаптивні контейнери.
- `src/css/utilities.css` — допоміжні класи доступності.
- `src/main.js` — майбутня ініціалізація інтерактивних елементів.
- `src/img/` — зображення секцій, які додаватимуться під час реалізації.
- `src/public/favicon.svg` — оригінальна камера з UI Kit Figma.
- `docs/implementation-plan.md` — етапи та погоджені правила роботи.

Шрифт DM Sans постачається локально через `@fontsource-variable/dm-sans` із
`font-display: swap`, без запитів до Google Fonts. Ліцензія OFL-1.1 міститься в
пакеті. Підключено звичайне та курсивне накреслення і розширену латиницю. Для
кирилиці використовується системний резервний шрифт: поточний DM Sans не містить
українських символів.

## Принципи реалізації

- Макет Figma має пріоритет перед ТЗ; додаткові вимоги користувача мають
  пріоритет.
- Mobile First, підтримка від 320 px. Контейнери для макетів 375, 768, 1280 і
  1440 px мають внутрішні відступи 20, 32, 50 і 100 px відповідно.
- Базові кольори: фон `#121212`, текст `#ffffff`, акцент `#bea69e`.
- Один `h1`, послідовна ієрархія заголовків, іменовані секції, списки для
  переліків; посилання для переходів і кнопки для дій.
- Інтерактивні елементи мають доступний фокус; є посилання переходу до основного
  вмісту та врахування налаштування зменшення руху.
- Початкова мова — англійська, як у макеті. Переклад реалізується на етапі 9.

## Поточний стан

Етап 1: підготовлено інструменти, базові стилі, favicon та структуру секцій.
Сторінка наразі показує лише заголовки майбутніх блоків. Їхній дизайн,
зображення, форми та поведінка реалізовуватимуться наступними етапами.

## Публікація

Workflow `.github/workflows/deploy.yml` після push у `main` встановлює
залежності через `npm ci`, перевіряє форматування, збирає сайт і публікує
`dist/` у гілку `gh-pages`. Для цього workflow має `contents: write`.

У GitHub відкрий **Settings → Pages** і вибери **Deploy from a branch**, гілку
**gh-pages**, папку **/ (root)**.

Адреса сайту: https://vadym-gr.github.io/FocusFrame-2.0/. Деплой можна запустити
вручну через **Actions → Build and deploy to GitHub Pages → Run workflow**.

Commit і push виконує власник репозиторію після кожного завершеного етапу.
