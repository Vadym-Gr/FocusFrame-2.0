# FocusFrame 2.0

Адаптивний сайт школи фотографії за макетом Figma. Стек: семантичний HTML, CSS і
JavaScript, збірка Vite. Початкова версія працює без бекенду.

[Макет Figma](https://www.figma.com/design/RXTP1SehqgqMzpvxD82chE/FocusFrame-2.0--Copy-?node-id=0-1)

## Локальний запуск

Потрібні Node.js 24 та npm. Версію Node.js також зазначено в `.nvmrc`.

```sh
npm ci
npm run dev
```

Адреса сервера з'явиться в терміналі; зазвичай це http://localhost:5173/. У
Windows PowerShell, якщо запуск `npm.ps1` заборонено, використовуй `npm.cmd`
замість `npm`.

## Команди

| Команда                | Призначення                                 |
| ---------------------- | ------------------------------------------- |
| `npm run dev`          | Сервер розробки з автоматичним оновленням   |
| `npm run build`        | Production-збірка в `dist/`                 |
| `npm run preview`      | Локальний перегляд production-збірки        |
| `npm run format`       | Форматування вихідного коду та документації |
| `npm run format:check` | Перевірка форматування без змін файлів      |

Після `npm run build` та `npm run preview` відкрий адресу з термінала зі шляхом
`/FocusFrame-2.0/` (зазвичай http://localhost:4173/FocusFrame-2.0/).

## Структура

- `src/index.html` — метадані та підключення секцій.
- `src/partials/` — семантична розмітка окремих блоків.
- `src/css/styles.css` — точка підключення нормалізатора, шрифтів і стилів.
- `src/css/tokens.css` — спільні кольори, шрифти та інші базові значення.
- `src/css/container.css` — адаптивні контейнери.
- `src/css/utilities.css` — допоміжні класи доступності.
- `src/main.js` — майбутня ініціалізація інтерактивних елементів.
- `src/img/` — зображення секцій, які додаватимуться під час реалізації.
- `src/public/favicon.svg` — оригінальна камера з UI Kit Figma.
- `docs/implementation-plan.md` — етапи та погоджені правила роботи.

Шрифт DM Sans постачається локально через `@fontsource-variable/dm-sans` із
`font-display: swap`, без запитів до Google Fonts. Ліцензія OFL-1.1 міститься в
пакеті. Підключено звичайне та курсивне накреслення і розширену латиницю. Для
кирилиці використовується системний резервний шрифт: поточний DM Sans не містить
українських символів.

## Принципи реалізації

- Макет Figma має пріоритет перед ТЗ; додаткові вимоги користувача мають
  пріоритет.
- Mobile First, підтримка від 320 px. Контейнери для макетів 375, 768, 1280 і
  1440 px мають внутрішні відступи 20, 32, 100 і 100 px відповідно.
- Базові кольори: фон `#121212`, текст `#ffffff`, акцент `#bea69e`.
- Один `h1`, послідовна ієрархія заголовків, іменовані секції, списки для
  переліків; посилання для переходів і кнопки для дій.
- Інтерактивні елементи мають доступний фокус; є посилання переходу до основного
  вмісту та врахування налаштування зменшення руху.
- Початкова мова — англійська, як у макеті. Переклад реалізується на етапі 9.

## Поточний стан

Завершено етапи 1–6: підготовлено основу проєкту, header, Hero, слоган, About
Us, Our Courses, Our Mentors і форму Sign Up. Для карток працює спільний
механізм перегляду. На desktop показано навігацію і Sign Up, на планшеті —
бургер і Sign Up, на мобільному — бургер і кнопку з камерою для переходу до Sign
Up.

Мобільне меню реалізовано через нативний модальний `dialog`: воно відкривається
праворуч, затемнює фон, блокує прокручування сторінки та утримує клавіатурний
фокус. Закривається кнопкою, Escape, натисканням поза панеллю, вибором секції
або переходом на desktop. Після закриття фокус повертається до кнопки меню;
після вибору секції — переходить до відповідної секції.

Логотипи, іконки та фотографії меню взяті з Figma й збережені локально;
фотографії мають варіанти 1× і 2×.

Hero містить адаптивну фотографію викладача, портрети студентів та посилання на
відгуки. Слоган статичний, як у макеті; його текст візуально виходить за межі
мобільного й планшетного екранів, але не створює горизонтального прокручування.
About Us змінює компонування тексту та кадрування камери залежно від ширини. Для
растрових зображень використовуються `picture` і `srcset` із варіантами 1×/2×;
декоративна сітка — оригінальний SVG, чіткий на будь-якій щільності.

Our Courses показує одну картку на мобільному, дві на планшеті й три на desktop.
Шеврони розташовані обабіч карток по центру їхньої висоти. На межах списку
відповідна кнопка неактивна; якщо видно всі картки, неактивні обидві. Працюють
свайпи, клавіші ←/→, Home/End та перехід Tab до посилань у картках. Стрілка
всередині картки веде до Sign Up. Автоматичного перемикання немає.

Механізм у `src/js/carousel.js` і стилі `src/css/carousel.css` використовуються
для курсів і менторів; далі підключимо відгуки. Він реагує на зміну ширини та
кількості карток, враховує зменшення руху й повідомляє поточний діапазон для
скринридерів. Без JavaScript усі картки показуються сіткою, а шеврони приховані.

Our Mentors містить чотири оригінальні портрети 180×180 px із варіантами 2×,
імена та досвід із Figma. Одночасно видно одну картку на мобільному, дві на
планшеті та чотири на desktop. Працюють ті самі шеврони, свайпи й клавіатура;
каруселі курсів і менторів перемикаються незалежно одна від одної.

Sign Up має обов'язкові поля імені, email і повідомлення, пов'язані підписи,
перевірку порожніх значень та email. Обмеження довжини — 100, 254 і 2000
символів відповідно. Помилки показуються біля полів; після натискання Send фокус
переходить до першого некоректного поля. За наявності помилок введені дані
залишаються.

Після коректного заповнення форма очищується й показує повідомлення про
перевірку та відсутність підключеного надсилання. Дані не надсилаються й не
записуються в локальне сховище. Без JavaScript кнопка Send неактивна. Privacy
Policy поки є неактивною заглушкою; текст згоди, включно зі згадкою Promodo,
збережено з Figma.

Декоративні фотографії камери й об'єктива показуються лише на desktop. Оригінали
мають роздільність, достатню для відображення 2× без збільшення вихідних
зображень.

Відгуки та footer залишаються каркасами для наступних етапів.

## Публікація

Workflow `.github/workflows/deploy.yml` після push у `main` встановлює
залежності через `npm ci`, перевіряє форматування, збирає сайт і публікує
`dist/` у гілку `gh-pages`. Для цього workflow має `contents: write`.

У GitHub відкрий **Settings → Pages** і вибери **Deploy from a branch**, гілку
**gh-pages**, папку **/ (root)**.

Адреса сайту: https://vadym-gr.github.io/FocusFrame-2.0/. Деплой можна запустити
вручну через **Actions → Build and deploy to GitHub Pages → Run workflow**.

Commit і push виконує власник репозиторію після кожного завершеного етапу.
